# deadlatch.dev

The site for **Deadlatch**, the open runtime governance stack for AI agents.

enforce · prove · watch. Purse · blackbox · Tripwire.

Built with Next.js (App Router) and deployed on Vercel. The homepage runs a live in-browser demo backed by a real policy engine and a genuine SHA-256 hash chain, no mockups.

## Develop

```bash
npm install
npm run dev
```

## The stack

- Purse (enforce), https://github.com/ArabianAnalyst/purse
- blackbox (prove), https://github.com/ArabianAnalyst/blackbox
- Tripwire (watch), https://github.com/ArabianAnalyst/tripwire
